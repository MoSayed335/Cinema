## 📖 Overview

Cinema Management System هو مشروع ويب مبني باستخدام ASP.NET Core MVC لإدارة نظام سينما متكامل.

تم الانتهاء من نظام Authentication & Authorization بالكامل.

---

## 🔐 Authentication System

- ✔ User Registration  
- ✔ Login / Logout  
- ✔ Email Confirmation  
- ✔ Custom OTP-Based Password Reset  
- ✔ Reset Password  
- ✔ Secure Password Hashing باستخدام ASP.NET Identity  

---

## 🔑 Authorization & Roles

- ✔ Role-Based Authorization  
- ✔ Multiple Admin Support  
- ✔ Admin Panel Protection  
- ✔ Dynamic Role Assignment  
- ✔ Route-Level & Controller-Level Authorization  

---

## 📧 Custom OTP Implementation

- Secure Random OTP Generation  
- Email Integration via SMTP  
- OTP Expiration Control  
- Prevent OTP Reuse  
- Limiting Attempts within 24 Hours  

---

## 🏗️ Architecture & Design Patterns

- Repository Pattern  
- Unit of Work Pattern  
- Dependency Injection  
- Separation of Concerns  
- ViewModels for Data Transfer
